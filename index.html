Horizon Launcher

لانشر خفيف لتشغيل ملفات jar على الأجهزة الضعيفة

تحميل اللانشر
ملف واحد · أقل من 20 كيلوبايت · لنظام Windows

مناسب لجهازك

المعالجCore 2 Duo E7400
الذاكرة2.5 جيجا، والافتراضي في اللانشر 1024 MB للعبة
وضع الأجهزة الضعيفةيشغّل Serial GC ويقلل حجم الـ stack
Java المطلوبةJava 8 (الأخف على جهازك)

طريقة الاستخدام

  1. ثبّت Java 8 من Adoptium.
  2. حمّل HorizonLauncher.jar وافتحه بنقرتين.
  3. اختر ملف jar الذي تريد تشغيله، واترك الذاكرة على 1024.
  4. اضغط «تشغيل». يظهر سجل التشغيل أسفل النافذة.

لو الملف لا يفتح

افتح CMD في مجلد الملف واكتب: java -jar HorizonLauncher.jar

اللانشر يشغّل ملفات jar التي تملكها فقط، ولا يحمّل ألعاباً ولا يتجاوز تراخيصها. للعبة ماين كرافت الأصلية استخدم حسابك من minecraft.net. وللجهاز الضعيف جداً جرّب لعبة Luanti المجانية.
